Html file that visualizes Psych Engine chart (json)                 
For kade engine chart, use jsm925's Funkin Chart                     
Tested with Psych Engine 1.0.4                          
If it desync go back to the start of the song                         
---  Notice  ---                                
Some mods have different voices files, split into opponent's voice and player's voice, so please name them correctly like this:                                   
Inst.ogg goes to Instrumental.                          
Voices-Opponent.ogg goes to the opponent voice.                              
Voices-Player.ogg goes to the player voice.                           
A single Voices.ogg goes to the player voice.                            
...or just use the buttons on top ._.                     
If a song only have 1 chart, no opponent's notes, then the player's notes might replace opponent's notes somehow
